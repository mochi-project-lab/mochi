Privacy policy

Last updated: October 5, 2026

Mochi is a browser extension and a website. This page explains what they collect, why, and what they never touch.

What we collect

  • Coin addresses you scan. When you hover or scan a token, the token or trading-pair address is sent to the Mochi server so it can look up public on-chain data, market data and social links.
  • Domains you check. For site checks, the extension sends only the site's domain (not the path or query) and a few simple signals about the page: whether it shows a "connect wallet" button, whether it has a field that asks for a seed phrase, and, only if one of those is present, the page title. It does not send the page content for this.
  • Chat messages. When you type in the pet's chat, your message is sent together with the page address, title and a trimmed part of the visible page text (up to about 4,000 characters), so the pet can answer about the page. Page text is sent only when you chat.
  • Basic request data. Like any web server, ours sees your IP address. We use it only for rate limiting and abuse protection and do not keep it in long-term logs.

How it is processed

Requests are processed by the Mochi server. To write the verdicts and chat replies, the server sends the relevant data (coin facts, domain facts, your chat message and page text) to a large language model provider, currently OpenRouter. The server also queries public sources such as blockchain RPC nodes, market data APIs, domain registration records and public social profiles.

Scan results are cached for a short time (minutes for coins, hours for domains) so repeat checks are fast. Chat messages are not stored after the reply is sent.

Your own API key

You can add your own OpenRouter key in the extension settings. It is stored only in your browser (chrome.storage) and is sent with your requests so the server can use it instead of ours. The server does not log or store it.

What stays on your device

Your settings (pet name, colour, personality, which features are on) are stored locally in chrome.storage. On the website, your pet settings and your last five checks are stored in your browser's local storage. None of this is sent to us except as part of a request you make.

What we never collect

  • Wallet private keys or seed phrases.
  • Signatures or transactions. Mochi never asks you to sign anything and cannot send transactions.
  • Your browsing history. Pages are checked only when you hover a coin on a supported site, open a page with a wallet prompt, run a command, or chat.
  • Passwords, form contents or cookies.

Sharing and selling

We do not sell your data. We do not use it for advertising. We share it only with the services needed to answer your request (the LLM provider and the public data sources above).

Not financial advice

Scores and verdicts are automated reads of public data. They can be wrong. Do your own research.

Changes and contact
